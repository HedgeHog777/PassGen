# PassGen

Simple password generator written in C#.

## Purpose

Навчитися працювати з Windows Forms/WPF, рядками та генерацією випадкових символів.

## Features

- генерація паролів
- довжина
- цифри
- спецсимволи

- Cryptographically secure password generation
- Configurable password length
- Letters
- Numbers
- Symbols


## Technologies

- C#
- .NET

## Purpose

A small educational project created during college to practice C# and secure random number generation.

Completed (College project)
